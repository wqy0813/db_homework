# 项目文件用途与重复关系盘点

盘点日期：2026-10-10。本文最初用于整理前盘点；本轮整理先将原始 Git 差异和未跟踪文件备份到 `D:\db_homework_cleanup_backup_20261010`，并在 `codex/project-cleanup` 分支操作。

## 先看结论

- 当前产品主线是 `frontend/` Vue 源码 + `backend/` Flask API + MySQL；启动入口是根目录 `start_website.bat`。
- `backend/static_web/` 是 Vue 构建产物；本轮已改为 Vite 直接输出并清理旧 hash 文件，目前是 22 个资源。
- 数据库中的 906 条演出/系列海报 URL 均使用 `/posters/`，82 个唯一海报 URL 检查均返回 200。与原件相同的运行副本已移到外部备份，`poster_collect/A-D/` 是唯一海报维护来源。
- 新库系列/IP 种子数据已整合进 `sql/seed/seed_data.sql`；旧迁移和旧系列种子脚本已移入 `sql/archive/`。`sql/schema/views.sql` 仍用于已有库单独刷新视图。
- API 说明、项目结构说明、部署手册和数据库设计正文已更新，明确当前新库和海报流程。
- 两个数据字典 Word 文件是同一主题的完整版/紧凑版；数据库模型有 Markdown、HTML、PPT 三种交付格式，内容有较大重叠，但适用场景不同。
- 整理前 Git 工作区已有大量修改、新增和删除（包括 API、海报、启动脚本和构建产物）；本轮保留这些改动并在上述外部目录备份。

### API 子模块职责

- `auth.py`：身份会话。
- `shows.py`：游客可见内容查询。
- `orders.py`：购票和订单。
- `profile.py`：用户资料。
- `admin.py`：管理员维护。
- `stats.py`：销售统计。
- `helpers.py`：共用身份和响应工具。
