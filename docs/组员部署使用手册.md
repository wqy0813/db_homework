# 组员部署使用手册（在自己电脑上运行演出门票销售系统）

本手册教你在一台新电脑上把系统跑起来，全程约 20~30 分钟。系统 = MySQL 数据库 + Flask 网站 + Navicat（可选，用于看数据）。

---

## 一、需要准备的软件

| 软件 | 版本要求 | 说明 |
|---|---|---|
| MySQL | **8.0**（必须 8.0） | 数据库。安装时记住你设置的 **root 密码** |
| Python | **3.7 或以上** | 运行网站（安装时勾选 Add to PATH） |
| Navicat for MySQL（或 Navicat Premium） | 任意 | 图形化看数据库、导入 SQL，方便测试 |

> 安装 MySQL 时若让你选认证方式，选默认的"Use Strong Password Encryption"即可；root 密码请务必记住。

## 二、拿到项目文件

把整个项目文件夹放到本机，例如 `D:\db_homework\`。核心文件：

```
db_homework\
├─ sql\schema\ddl.sql  建库建表（含视图）——必跑
├─ sql\seed\seed_data.sql    测试数据（演出、订单、账号）——必跑
├─ scripts\data\gen_more_data.py  （可选）更丰富的演示数据
├─ scripts\data\gen_full_scale.py    （可选）生成满规模大数据
├─ poster_collect\     海报原图和来源登记
├─ backend\             网站程序（Flask）
│   ├─ app.py            后端
│   ├─ config.py         ★数据库密码在这里改
│   ├─ requirements.txt  依赖清单
│   ├─ static_web\       已构建的 Vue 前端
│   └─ static\           Flask 静态目录（管理员上传内容）
└─（其余 .md 是文档，.sql 是查询/测试脚本）
```

> 注意：**不要**复制别人电脑上的 `.mysql` 隐藏文件夹（那是本机数据库运行数据，机器相关）。你在自己电脑上用下面第三步重新建库即可。

## 三、启动 MySQL 并导入数据库（Navicat）

1. 确认 MySQL 服务已启动（Windows 服务里 `MySQL80` 状态为"正在运行"；没启动就启动它）。
2. 打开 Navicat → 左上角 **连接 → MySQL**，填：主机 `127.0.0.1`、端口 `3306`、用户名 `root`、密码=**你安装 MySQL 时设的密码** → 测试连接 → 确定。
3. 双击打开这个连接。
4. 右键连接名 → **运行 SQL 文件…** → 选 `sql/schema/ddl.sql`，编码选 `65001 (UTF-8)` → 开始（成功提示 Finished successfully）。
5. 双击打开新出现的数据库 `ticket_sales`，右键它 → **运行 SQL 文件…** → 选 `sql/seed/seed_data.sql` → 开始。
6. 右键连接 → 刷新。展开 `ticket_sales` → "表"里应有 16 张表（show_item、show_series、ticket_order 等），"视图"里有 v_show_list、v_tier_stock、v_order_detail。

> 自检：新建查询运行 `SELECT COUNT(*) FROM ticket_sales.show_item;` 应返回 **7**。

## 四、配置网站连数据库的密码

`backend\config.py` 默认不设置数据库密码。若 MySQL root 账号设置了密码，在 PowerShell 中先设置 `DB_PASSWORD`，再从同一窗口启动网站：

```powershell
$env:DB_PASSWORD = '你的 MySQL root 密码'
.\start_website.bat
```

也可以在 Windows 用户环境变量中设置 `DB_PASSWORD`，供双击启动器使用。不要把真实密码写入代码或提交到 Git。

## 五、安装 Python 依赖并启动网站

**方式一（推荐）：双击 `start_website.bat`**
- 先按本节方式安装一次 Python 依赖，再双击脚本启动 MySQL 和网站；
- 看到 `Running on http://127.0.0.1:5000` 即成功。

**方式二（命令行）：**
```bat
cd /d D:\db_homework\backend
pip install -r requirements.txt
python app.py
```

启动后，浏览器打开 **<http://127.0.0.1:5000/app/>**。
⚠️ 运行期间**不要关闭**那个黑色命令窗口（关了网站就停了）。

## 七、（可选）让数据更丰富

基础数据只有 8 场演出、9 笔订单。想让列表和管理员统计图表更饱满：

- **中等数据（约 57 场演出、1000+ 订单）**：在项目根目录运行
  ```bat
  cd /d D:\db_homework
  pip install pymysql
  python scripts\data\gen_more_data.py
  ```
- **满规模大数据（10 万用户、约 1000 场次、约 100 万张票，约 10 分钟）**：`python scripts\data\gen_full_scale.py`，跑完可用 `python scripts\performance\perf_check.py` 看性能实测。

两个脚本都**可重复执行**（会先清理自己生成的那批数据，不影响 5 个演示账号）。想回到基础数据，重新运行一次 `sql/seed/seed_data.sql` 即可。

## 八、常见问题

| 现象 | 解决 |
|---|---|
| 网页报 `Can't connect to MySQL / 10061` | MySQL 服务没启动；或网站没连上。确认 MySQL80 服务在运行，`config.py` 密码正确 |
| 网页报 `1045 Access denied` | `config.py` 里密码填错了，改成你自己的 root 密码 |
| 网页报 `1146 / Table ... doesn't exist` | 没导入 SQL，回到第三步跑 `sql/schema/ddl.sql`、`sql/seed/seed_data.sql` |
| `python` 或 `pip` 不是内部命令 | Python 没装好或没加入 PATH，重装 Python 时勾选 Add to PATH |
| Navicat 运行 SQL 报中文乱码 | 运行 SQL 文件时编码选 `65001 (UTF-8)` |
| 提示 `Unknown collation utf8mb4_0900_ai_ci` | 你的 MySQL 是 5.7，请卸载改装 8.0 |
| 5000 端口被占用 | 关掉占用的程序，或把 `app.py` 最后一行 `port=5000` 改成 `5050` |

部署完成后，按项目根目录 `README.md` 的“测试”章节验证 API、海报和页面流程；购票测试会写入订单，请使用可恢复的演示数据库。
