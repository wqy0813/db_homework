# 演出门票销售系统 —— Web 演示系统（Flask + MySQL）

真实连接 `ticket_sales` 数据库的可运行小系统，覆盖题目中游客/用户/管理员三种角色的全部功能。

## 一、启动步骤（3 步）

### 1. 确保 MySQL 已启动且数据库已导入

**本机已配置好独立数据库（推荐，免管理员、密码已设好）：**
- 若数据库没在运行，**双击 `D:\db_homework\启动MySQL数据库.bat`** 即可（端口 3306，root / Wqy0813）；
- 该数据库已导入 `ticket_sales` 全部表、视图和测试数据，无需再跑 SQL 脚本；
- Navicat 连接：主机 `127.0.0.1`、端口 `3306`、用户 `root`、密码 `Wqy0813`。

（备选：若你用自己安装的 MySQL80 服务，则启动它并在 Navicat 运行 `ddl.sql`、`seed_data.sql`，再把 `config.py` 密码改成你自己的。）

### 2. 数据库密码（已配置好）

`config.py` 默认已配置为 `127.0.0.1:3306`、用户 `root`、密码 `Wqy0813`，与上面的独立数据库一致，**一般无需修改**。

### 3. 安装依赖并启动

```bash
cd D:\db_homework\app
pip install -r requirements.txt
python app.py
```

或直接**双击 `run.bat`**。看到 `Running on http://127.0.0.1:5000` 后，浏览器打开 <http://127.0.0.1:5000>。

## 三、功能清单

### 游客（无需登录）
- 登录（用户名+口令，后端比对，失败提示/成功跳转）；
- 演出列表：按**城市、类型**筛选、按名称搜索；每行显示名称、地点、最近演出日期、票价（最低-最高）、售票状态徽标；
- 演出详情：介绍文字+多张图片、若干演出日期（场次）、各场票档余票，**无余票的票档显示"该票档售罄"**。

### 用户（登录后）
- **购票**：在详情页选择场次下的票档、票数（1-6）、收货地址、勾选购票人（JS 校验"购票人数=票数"，后端强制每人每场次 1 张）；
  - 余票原子扣减（`UPDATE ... WHERE 余票>=票数`），**不超卖**；
  - 成功/失败都有页面提示，且**所有购票请求写入 purchase_request 留痕**；
- **我的订单**：订单号、演出名称、地点、演出日期、票数、金额、交易状态、收货信息、每张票的持票人；
- **收货信息管理**：新增/删除（收货人、手机号、地址）；
- **常用购票人管理**：新增/删除（姓名、证件类型、证件号，重复证件被唯一约束拦截）。

### 管理员（admin 登录）
- **演出管理**：新建演出（名称/城市/类型/海报/介绍）、编辑、删除（级联删除场次/票档/图片，有订单的演出拒绝删除）；
  为演出添加多个**场次**（场馆、开演时间、开售时间）、为每个场次添加多个**票档**（名称、金额、票数）；
- **销售统计**：选择时间段，页面展示
  - 成交订单数/售票张数/销售金额三个指标卡；
  - **每日销售趋势折线图**、**各类型销售额饼图**、**各城市售票数柱状图**（ECharts 本地渲染，无需联网）；
  - 热销演出 TOP10 表格。

## 五、技术说明

- 后端：Flask + PyMySQL（事务手写，购票在单事务内完成"留痕→扣票→限购校验→订单→明细→支付"）；
- 前端：Jinja2 服务端渲染 + 原生 CSS + ECharts 5（`static/lib/echarts.min.js` 已本地化）；
- 售票状态推进：数据库事件 `ev_session_status` 每 10 分钟自动推进（预售中→售票中→售罄），
  前端展示以表中 `sale_status` 为准。

## 六、常见问题

| 现象 | 解决 |
|---|---|
| 启动报 `Access denied for user 'root'` | `config.py` 中密码不对（独立库应为 `Wqy0813`） |
| 报 `Can't connect to MySQL server` / 10061 | 数据库没启动：双击 `D:\db_homework\启动MySQL数据库.bat`（或直接双击 `app\run.bat` 会自动拉起） |
| 报 `Unknown database 'ticket_sales'` | 还没运行 `ddl.sql` 建库（独立库已建好） |
| 页面 1146/视图不存在 | 运行一次 `views.sql`（或重新运行新版 `ddl.sql`） |
| 图表空白 | 确认时间段内有"已支付"订单；把开始日期选早一些（基础数据下选近 30 天；扩充数据后有 90 天数据） |
| 端口 3306 冲突 | 不要启动系统服务 MySQL80（忘记密码那个），本系统用独立数据库 |
